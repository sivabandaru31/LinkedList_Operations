🚀 Singly Linked List Operations in Java
📖 Overview

This project demonstrates the implementation of a Singly Linked List from scratch using Java. It provides a clear understanding of how linked lists work internally without using Java's built-in collection framework.

The project focuses on implementing fundamental linked list operations using object-oriented programming concepts and dynamic memory allocation.

✨ Features
✅ Insert a node at the beginning
✅ Insert a node at the end
✅ Insert a node at a specific position
✅ Traverse and display the linked list
✅ Handle invalid insertion positions
✅ Maintain Head and Tail references
✅ Track the size of the linked list
🛠️ Technologies Used
Java
Object-Oriented Programming (OOP)
📂 Project Structure
LinkedList/
│── Main.java          // Driver class
│── Node.java          // Node structure
│── Operations.java    // Linked List operations
📚 Linked List Operations
1. Insertion at Beginning

Adds a new node at the beginning of the linked list.

2. Insertion at End

Adds a new node at the end of the linked list.

3. Insertion at Specific Position

Inserts a new node at the specified position while maintaining the list structure.

4. Traversal

Traverses the linked list from head to tail and displays all node values.
